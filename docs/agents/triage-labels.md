# Triage labels

Use this mapping whenever an engineering skill names a triage role.

| Skill role        | GitHub label      | Meaning                            |
| ----------------- | ----------------- | ---------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer evaluation              |
| `needs-info`      | `needs-info`      | Waiting for reporter information   |
| `ready-for-agent` | `ready-for-agent` | Specified for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation      |
| `wontfix`         | `wontfix`         | Will not be actioned               |

Edit the GitHub label column to change the mapping.
